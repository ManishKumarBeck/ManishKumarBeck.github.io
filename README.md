# Manish Kumar Beck: portfolio

Personal portfolio site, live at **https://manishkumarbeck.github.io/** once deployed.

It is a static site generated by a small Python script. There is no JavaScript
framework, no server and no secrets. GitHub Actions builds it and publishes it
to GitHub Pages on every push to `main`.

## Run it locally

Requires Python 3.10 or newer.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1      # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python build.py --serve
```

Open http://localhost:8000. Run `python tests/check_site.py` after a build to
check internal links, anchors, alt text, page metadata and secrets. CI runs the
same check and blocks the deploy if it fails.

## Edit the content

All copy lives in YAML, so most changes never touch the markup.

| File | Controls |
| --- | --- |
| `content/site.yaml` | Name, hero, about, contact details, SEO text, hero trace |
| `content/experience.yaml` | Employment, education, build log |
| `content/skills.yaml` | Skill groups. `shown: true` marks a skill as visible in a public project |
| `content/projects.yaml` | Featured projects, case studies, Play Store apps |
| `content/work.yaml` | Earlier Unity, AR and VR work |

**Resume button:** add your CV as `static/resume.pdf`. The Download Resume button
appears automatically on the next build.

## Project layout

```
build.py              Renders templates + content into dist/
content/              Site copy (YAML)
templates/            Jinja templates
static/               CSS, JS, fonts, optimised media, Open Graph image
tests/check_site.py   Static checks on the build output (standard library only)
.github/workflows/    Build, check and deploy to GitHub Pages
```

## Deploy

One-time setup:

1. Create an empty **public** repository named exactly `ManishKumarBeck.github.io`.
   Do not add a README, licence or .gitignore.
2. In that repository open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Push this folder. The first command puts the workflow file where GitHub expects it:

   ```powershell
   mkdir .github\workflows -Force; Move-Item setup\deploy.yml .github\workflows\deploy.yml; Remove-Item setup
   git init -b main
   git add .
   git commit -m "Initial portfolio site"
   git remote add origin https://github.com/ManishKumarBeck/ManishKumarBeck.github.io.git
   git push -u origin main
   ```

4. Watch the run in the **Actions** tab. When it is green the site is live.

After that, every push to `main` redeploys. To host under a different repository
name instead, set `base: /repo-name/` and `url` in `content/site.yaml`.
